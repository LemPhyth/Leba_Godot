## 转换方法与重跑

在工作区执行：

```powershell
python godot/tools/import_runtime_assets.py
python godot/tools/import_runtime_assets.py --verify
```

依赖沿用现有 Python/Pillow、Java、FFDec26.2.1。导入器只读 `leba/雷巴的冒险EX.swf`、同级`res/`与`tools/swf/vendor/ffdec`，目标只允许`godot/assets`和派生catalog。先核对原SWF SHA256：`afef4c43153780e9140eca7234b5af26c4a751596efefeb071d35428435a909d`。已有输出若不在上一catalog登记、或哈希已被用户修改，拒绝覆盖；未登记用户文件不会被清理。

每个元件只选表内必要帧。多个动作共用同一元件时先合并精确帧集合，再渲染一次，例如7170包含idle/近攻/远攻/hit，而不是后一条覆盖前一条。不会把整个7170或全部原始资源复制入工程。

默认服装/装备分支在**内存SWF副本**上固定，源文件从不保存：3725、3763及动作中新用的3620补入原有stop选择器名单；3588隐藏wing/전펙，3620隐藏wing。3620遗漏会导致S恢复帧依次换衣服和出现翅膀，首次视觉抽查发现后已修正并重新生成。没有把所有未知嵌套动画一律冻结。

几何继续用FFDec的滤镜矩形、动作统一alpha并集裁剪、2px透明隔离和固定pivot。旋转/缩放/嵌套由源渲染器处理。4917父scale为非1，其像素保留原样，动画定义新增`parent_scale`；pivot为`-bounds_min/20 - union_min - parent_offset/scale`。绘制应采用`Rect2(-pivot*scale,region.size*scale)`，才能同时保持原始平移与缩放。alpha_bounds也写入同一父坐标缩放。旧动画scale全为1，旧键和坐标合同保留。

catalog记录原ID、源帧范围、原始PNG和参与AS/XML/SWF/工具的哈希、导出帧哈希、输出文件哈希、裁剪和父变换。源PNG是完整提取库里的追溯项；实际角色图集使用内存默认分支重新导出帧，不把此前未经脚本处理的PNG冒充默认服装。

## 验证与边界

本轮资源阶段一次成功生成：**30个动画定义、736个选帧、45个去重输出文件、10,685,389字节**（包含此前工单01已用资源）。`--verify`通过1006个源文件哈希、45个输出哈希、RGBA/透明隔离、图集区域与有限pivot检查。转换完成后重新核验所读源文件哈希，未发现原始输入发生变化。

工具视觉查看了crt0旧X图集、crt0/1 S图集和7176近攻图集。修正后的角色默认衣服不再逐帧变化，翅膀已按源码隐藏；Boss近攻方向与源默认朝左一致。此检查属于派生图集静态视觉，不等于Godot游戏内视觉、音频听感或原版动作调度验收。

尚需由整体回归确认：SourceSprite是否应用parent_scale、实际动作分段/跳帧/音效事件、攻击命中、空中视觉、声音循环与切换，以及Ruffle和原生Flash的差异。本轮不凭资源导入通过宣布角色或游戏全部还原。
