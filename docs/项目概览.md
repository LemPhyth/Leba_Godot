## 工程接入时的关键约束

`res/` 是工作区的素材目录名。若新工程放在 `godot/`，Godot 的 `res://` 指向包含 `project.godot` 的工程根目录，即 `godot/`；它不会因为同级目录叫 `res` 就自动指向那里。应先确定原始资料到运行时素材的选取、转换和导入流程。[Godot 4.6 路径说明](https://docs.godotengine.org/en/4.6/tutorials/io/data_paths.html)

建议先为一个可玩切片选取必要素材，将其作为工程内可追溯的运行时资源。当前精灵 PNG 约2.19 GB，完整 XML 约586 MB；原始资料的文件体积不能直接作为最终导入成本的测量结果。Godot 导入会产生 `.import` 和缓存，应以小批量实测结果决定后续图集、裁剪、压缩和打包方案。[Godot 4.6 导入流程](https://docs.godotengine.org/en/4.6/tutorials/assets_pipeline/import_process.html)

原作是25 FPS 的 Flash 时间轴程序。输入、动作帧、伤害和全局状态相互引用，直接替换图片或复制数值不足以保证相同手感。需要先确定动作帧与游戏逻辑的时间基准，再逐项对照原作。
